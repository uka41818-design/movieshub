MOVIESHUB FINAL
1. Install Node.js.
2. Extract this ZIP.
3. In the folder run: npm install
4. Set ADMIN_PASSWORD to your own strong password.
5. Run: npm start
6. Open http://localhost:3000
7. Admin: http://localhost:3000/admin.html

For public access, deploy to a Node.js server/host with persistent storage and HTTPS.
Only upload content you own or are licensed to distribute.
The public page has Watch and Download controls. Actual download behavior can depend on the browser/storage provider.
